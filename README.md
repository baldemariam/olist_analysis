# Analyse E-Commerce Olist

Projet d’analyse de données réalisé avec Python et Pandas à partir du dataset Olist E-Commerce.

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## Objectifs
- Nettoyage des données
- Analyse des ventes
- Analyse des délais de livraison
- Visualisation des données

## Lancer le projet

```bash
pip install pandas numpy matplotlib seaborn
jupyter notebook
```
